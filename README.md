# Object-Detection-Using-Iot-and-ML-To-avoid-Accidents
IoT-based Road Accident Prevention System using Machine Learning and YOLOv Object Detection. This project detects vehicles, people, and obstacles in real time using ML Model and Arduino IoT integration to generate warning alerts and help prevent road accidents.
# IoT Object Detection for Road Accident Prevention 🚗⚠️
## 🚀 Features
- Real-time Object Detection
- Vehicle & Pedestrian Detection
- Arduino IoT Integration
- Warning Buzzer Alert
- Machine Learning using YOLO data models
- Live Camera Monitoring
- Accident Prevention System
- ## 🛠️ Technologies Used
- Python
- OpenCV
- YOLO
- Arduino UNO
- IoT Sensors
- Machine Learning
